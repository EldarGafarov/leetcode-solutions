# LeetCode Solutions

My LeetCode practice repo while preparing for software engineering interviews (junior to mid level). The goal is learning, not collecting solutions: I solve each problem myself, explain my reasoning, and write down what I learned.

## How I practice

- Talk through the approach before coding, as in a real interview.
- Start with a brute force solution, then improve it.
- State time and space complexity for every solution.
- Test edge cases (empty input, single element, duplicates, negatives, large input).

## Structure

```
Easy/
Medium/
Hard/
  <number>-<Problem_Name>/
    solution.py   # my solution
```
